# Copilot Autostart Killer - By LowiKLive

---

## 📌 Зачем этот инструмент?

В Windows 11 и 10 приложение Microsoft Copilot прописывается в систему через скрытый механизм **`startup task`** (`windows.startupTask` в манифесте приложения).

Из-за этого у большинства пользователей его **вообще не видно**:
- В Диспетчере задач на вкладке **«Автозагрузка»**
- В реестре в классических ключах `Run` / `RunOnce`
- В системной папке автозагрузки (`shell:startup`)
- В стандартном интерфейсе Планировщика задач

Обычными средствами Windows убрать его из автозапуска, не удаляя само приложение, практически невозможно. Этот набор скриптов решает именно эту задачу.

- ✅ **100% открытый код** - вся логика написана на понятном PowerShell, код можно изучить перед запуском.

## 🚀 Инструкция по использованию

1. Скачайте репозиторий (или ZIP-архив из [Releases](../../releases)).
2. Распакуйте архив в любую удобную папку (все файлы должны лежать рядом друг с другом).
3. Запустите файл **`1_Отключить_автозапуск_Copilot.bat`**.
4. В появившемся окне контроля учётных записей (UAC) нажмите **«Да»** *(важно: входите под своим аккаунтом, а не под чужим)*.
5. Дождитесь надписи **«ГОТОВО»**.
6. Перезагрузка компьютера **не требуется**.

### Проверка результата:
Запустите `2_Проверить_статус.bat`. В отчёте должно отображаться:
```text
State = 3 -> ВЫКЛЮЧЕНА (запрет политикой)
```

## ⚙️ Как это работает под капотом

1. **Блокировка задачи `startupTask`:**  
   Скрытая системная задача Copilot в ветке `HKCU:\Software\Classes\Local Settings\Software\Microsoft\Windows\CurrentVersion\AppModel\SystemAppData` переводится в системное состояние `State = 3` (**`DisabledByPolicy`**). В этом состоянии приложение не может повторно включить автозапуск через Windows API.
2. **Активация системных политик Windows:**  
   Включается параметр `TurnOffWindowsCopilot = 1` сразу в трёх системных ветках:
   - `HKLM:\Software\Policies\Microsoft\Windows\WindowsCopilot`
   - `HKCU:\Software\Policies\Microsoft\Windows\WindowsCopilot`
   - `HKLM:\Software\Policies\Microsoft\Windows\WindowsAI`
3. **Фоновый сторож (`CopilotAutostartGuard`):**  
   В Планировщик задач регистрируется легковесная фоновая задача, которая при каждом входе пользователя в систему проверяет статус. Если апдейт Copilot попытается сбросить автозапуск, сторож тихо вернёт состояние `DisabledByPolicy`.

## 🔄 Резервная копия и откат

Перед внесением любых изменений скрипт автоматически сохраняет исходные значения реестра в файл:
```text
%LOCALAPPDATA%\CopilotAutostartGuard\backup.json
```
При запуске `3_Вернуть_как_было.bat` система считывает этот файл и возвращает всё в исходный вид. Повторный запуск отката безопасен.

## ⚠️ Честный нюанс

Если Microsoft выпустит крупное обновление пакета Copilot, приложение может один раз запуститься при первом входе в систему после обновления (до того, как сторож успеет отработать). Начиная со следующего входа запусков больше не будет. Это фундаментальное ограничение самого механизма Windows AppModel.
