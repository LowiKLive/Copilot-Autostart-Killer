  ВАЖНО: ЗАПУСКАЙТЕ ИМЕННО .BAT ФАЙЛЫ
  --------------------------------------------------------------------------
  Все действия выполняются через .bat файлы:

    1_Отключить_автозапуск_Copilot.bat
    2_Проверить_статус.bat
    3_Вернуть_как_было.bat

  .bat - это только запускалка. Она сама вызывает нужный .ps1 файл
  с правильными параметрами: обходит ограничение "Выполнение сценариев
  отключено", при необходимости запрашивает права администратора (UAC)
  и только потом запускает логику.

  Поэтому НЕ надо открывать .ps1 напрямую (двойным кликом или через
  "Запустить с помощью PowerShell"). Так Windows может заблокировать
  выполнение скрипта, и он не отработает как задумано.

  Правильно: двойной клик по .bat (при желании - правой кнопкой ->
  "Запуск от имени администратора").

  Все файлы (.bat и .ps1) должны лежать в одной папке рядом друг с другом.


  ЗАЧЕМ ЭТО
  --------------------------------------------------------------------------
  Microsoft Copilot (он же Microsoft 365 Copilot) прописывает себя
  в автозагрузку через скрытый механизм Windows - "startup task"
  (windows.startupTask в манифесте приложения).

  Из-за этого его часто НЕ ВИДНО:
    - в Диспетчере задач на вкладке "Автозагрузка" (у многих его там нет)
    - в реестре в ключах Run / RunOnce
    - в папке "Автозагрузка"
    - в Планировщике задач

  При этом он всё равно стартует вместе с системой.

  Поэтому обычными способами его автозапуск не отключить.
  Удалить Copilot - легко и быстро. А вот просто убрать его
  из автозапуска, оставив приложение - вот это и есть та задача,
  которую решают эти скрипты.


  ЧТО В ПАПКЕ
  --------------------------------------------------------------------------
  1_Отключить_автозапуск_Copilot.bat   -  ОСНОВНОЙ. Отключает автозапуск.
  2_Проверить_статус.bat               -  показывает текущее состояние (только чтение)
  3_Вернуть_как_было.bat               -  откат всех изменений

  (все .bat - это просто запускалки; сама логика в .ps1 файлах)


  КАК ПОЛЬЗОВАТЬСЯ
  --------------------------------------------------------------------------
  1. Распакуйте папку целиком (все файлы должны лежать рядом).
  2. Запустите "1_Отключить_автозапуск_Copilot.bat".
  3. Нажмите "Да" в окне UAC.

     ВАЖНО: вводите СВОЙ аккаунт, а не логин/пароль другого
     администратора. Если ввести чужой - скрипт это заметит
     и остановится с предупреждением.
  4. Дождитесь надписи "ГОТОВО".
  5. Перезагрузка НЕ нужна.

  Проверить результат: "2_Проверить_статус.bat"
  Должно быть: State = 3 -> ВЫКЛЮЧЕНА (запрет политикой)


  ЧТО ИМЕННО МЕНЯЕТСЯ
  --------------------------------------------------------------------------
  1) Скрытая задача автозапуска Copilot переводится в состояние
     "DisabledByPolicy" (State = 3) - это принудительный запрет,
     а не просто "выключено пользователем".

  2) Включается политика Windows "Turn off Windows Copilot":
       HKLM\Software\Policies\Microsoft\Windows\WindowsCopilot
       HKCU\Software\Policies\Microsoft\Windows\WindowsCopilot
       HKLM\Software\Policies\Microsoft\Windows\WindowsAI

  3) В Планировщик задач ставится маленький "сторож"
     (имя задачи: CopilotAutostartGuard).
     При каждом входе в Windows он проверяет настройку и возвращает
     запрет, если обновление Copilot снова включило автозапуск.
     Файлы сторожа: %LOCALAPPDATA%\CopilotAutostartGuard\

  ВАЖНО: приложение Copilot НЕ удаляется. Оно остаётся установленным
  и запускается вручную как обычно.


  РЕЗЕРВНАЯ КОПИЯ И ОТКАТ
  --------------------------------------------------------------------------
  Перед изменениями скрипт сохраняет исходные значения в
  %LOCALAPPDATA%\CopilotAutostartGuard\backup.json

  Благодаря этому "3_Вернуть_как_было.bat" возвращает ИМЕННО то состояние,
  которое было у вас до запуска - даже если автозапуск у вас уже был
  выключен или политика уже стояла.

  Если резервной копии нет (например, её удалили) - откат честно
  сбросит автозапуск к состоянию Windows по умолчанию ("включено")
  и напишет об этом.

  Повторный запуск отката безопасен: резервная копия НЕ удаляется,
  поэтому второй откат вернёт то же самое состояние, а не включит
  автозапуск.

  Если набор вообще не запускался (нет ни сторожа, ни копии) - откат
  ничего не меняет и просто сообщает: "откатывать нечего".


  ОДИН ЧЕСТНЫЙ НЮАНС
  --------------------------------------------------------------------------
  Если Microsoft выпустит обновление, которое снова включит автозапуск
  Copilot, то Copilot может ОДИН РАЗ стартовать при следующем входе в
  систему - до того, как сторож успеет вернуть запрет. Со следующего
  входа запусков уже не будет.

  То есть "навсегда" здесь означает: настройка чинится автоматически
  и сама не возвращается. Абсолютно нулевой шанс на единственный
  запуск в момент обновления дать нельзя - это ограничение самого
  механизма Windows, а не скрипта.


  ЧЕГО СКРИПТЫ НЕ ДЕЛАЮТ
  --------------------------------------------------------------------------
  - Не удаляют программы
  - Не трогают автозагрузку других приложений
    (проверено: задачи автозапуска Claude и OpenAI Codex не затрагиваются)
  - Не отправляют данные в интернет
  - Не ставят ничего "втихую" - все действия видны в консоли


  ЕСЛИ ВДРУГ НЕ РАБОТАЕТ
  --------------------------------------------------------------------------
  - "Выполнение сценариев отключено" - запускайте именно .BAT файл,
    он сам обходит это ограничение.
  - Не появляется окно UAC - запустите .bat правой кнопкой ->
    "Запуск от имени администратора".
  - Антивирус ругается на .bat - это нормально для любых скриптов,
    меняющих реестр. Весь код открыт в .ps1 файлах, можно прочитать.
  - Если Copilot не установлен, скрипт просто сообщит об этом
    и ничего в системе не изменит.
